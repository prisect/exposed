# Exposed

Minecraft 26.3 Fabric mod. Press `I` to toggle.

Put it on both the client and the server if you can. Client-only still works for singleplayer / your own worlds.

Needs JDK 26. Compiles to Java 25.

```
.\gradlew.bat build
```

Jar: `build/libs/exposed-0.2.0.jar`

```
.\gradlew.bat runClient
```
